# 高校课程项目协作与评审平台

## 线上核验

**[打开线上系统](https://152.175.116.144/login) · [查看完整核验指南](线上核验指南.md)**

测试账户和密码如下：

使用项目组单独提供的账号和密码登录，在「我的课程」选择 **`软件工程_2024级1班`**，核验项目 **校园失物招领系统需求与设计**。

| 操作 | 核验点 |
| --- | --- |
| 1. 教师打开[项目详情](https://152.175.116.144/courses/3/projects/4)和[组队与选题](https://152.175.116.144/courses/3/teams) | 核对项目要求、评分标准、两支固定团队及所选项目。 |
| 2. 教师查看[迭代与任务](https://152.175.116.144/modules/tasks?courseId=3&projectId=4&teamId=8)和[成果与版本](https://152.175.116.144/modules/submissions?courseId=3&projectId=4&teamId=8) | 查阅任务分工，打开两版成果的「材料与回执」，可下载相应附件。 |
| 3. 助教查看[检查与复查](https://152.175.116.144/modules/reviews?courseId=3&projectId=4&teamId=8&tab=inspection) | 对照第 1 版整改意见和第 2 版通过记录。 |
| 4. 教师打开[同伴互评](https://152.175.116.144/modules/reviews?courseId=3&projectId=4)和[评分与成绩](https://152.175.116.144/modules/grades?courseId=3&projectId=4) | 核对 7 项已提交互评、两队已发布成绩 **89.30** 和 **90.80**，以及对应的第 2 版被评成果。 |
| 5. 切换为学生，打开[本人成绩](https://152.175.116.144/modules/grades?courseId=3&projectId=4) | 核对本人收到的项目成绩。切换账号前，请先退出当前账号。 |
