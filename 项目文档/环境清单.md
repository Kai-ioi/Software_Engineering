项目版本 0.1.0。本清单记录 2026 年 11 月 7 日验收环境，当前版本的启动步骤见[项目 README](../school_system/README.md)。课程演示与本地验收使用 Windows 上的前后端独立启动方式，数据库采用 H2 本地文件模式（demo）。

# 三 启动与构建

## 本机启动

**1 打开项目目录　**将项目解压到有写入权限的位置。在包含 backend、frontend、scripts 的 school_system 目录打开两个 PowerShell 窗口。

**2 启动后端　**在第一个窗口执行以下命令，等待后端启动完成。脚本默认以 demo 模式运行，端口为 8080。

powershell -ExecutionPolicy Bypass -File .\scripts\backend.ps1

**3 启动前端　**在第二个窗口执行以下命令。首次启动会安装依赖，Vite 将 /api 请求转发至本机后端。

powershell -ExecutionPolicy Bypass -File .\scripts\frontend.ps1

**4 打开并检查　**浏览器访问 http://127.0.0.1:5173。首次启动会初始化本地演示账号，登录方式见项目 README。后端检查地址为 http://127.0.0.1:8080/api/health，返回 UP 且模式为 demo。

如端口被占用，先确认并关闭占用端口的旧服务。正常停止时，在两个运行窗口分别按 Ctrl+C。

## 构建与产物

在同一项目目录执行以下命令。脚本构建前端并运行后端 Maven verify。

powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1

| 内容           | 项目内位置                             |
|----------------|----------------------------------------|
| 前端构建产物   | frontend/dist/                         |
| 后端可执行 JAR | backend/target/school-system-0.1.0.jar |
| 本地数据库     | backend/.runtime/demo-db.mv.db         |
| 上传文件       | backend/.runtime/files/                |

数据库和上传文件在重启后保留。课堂案例的课程、团队、成果和成绩随本机运行数据保存。使用新数据库时，可按《系统说明》重新创建课堂案例。

## 可选部署

项目另附 Docker Compose 部署配置，数据库镜像为 PostgreSQL 17.6 Alpine。容器方式使用 8088 访问网页，数据库默认绑定本机 5432。配置和启动步骤见项目 README 的 PostgreSQL 模式。课程演示使用上文的 H2 本地方式。
