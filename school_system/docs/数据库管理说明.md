# 浏览器数据库管理

## 打开和连接

1. 启动后端，保持运行。
2. 打开 http://127.0.0.1:8080/h2-console/ 。
3. Driver Class填 `org.h2.Driver`。
4. JDBC URL覆盖为下方完整内容。
5. User Name填 `sa`，Password留空，点击Connect。

```text
jdbc:h2:file:./.runtime/demo-db;MODE=PostgreSQL;DATABASE_TO_LOWER=TRUE;DEFAULT_NULL_ORDERING=HIGH;IFEXISTS=TRUE
```

地址按项目启动脚本的backend工作目录解析，连接的正是运行中的演示数据库。后端使用其他工作目录或自定义数据库地址时，控制台也应填写实际配置的数据库地址。

## 查看数据

左侧展开PUBLIC及数据表查看字段；右侧填写SQL，点击Run。可以先执行：

```sql
SELECT id, username, display_name, enabled, platform_admin
FROM app_user ORDER BY id;

SELECT * FROM course ORDER BY id;

SELECT c.name AS course_name, u.username, u.display_name,
       m.role, m.active
FROM course_membership m
JOIN course c ON c.id = m.course_id
JOIN app_user u ON u.id = m.user_id
ORDER BY c.id, u.id;

SELECT * FROM stored_file ORDER BY created_at DESC;

SELECT * FROM audit_record ORDER BY occurred_at DESC;
```

浏览器中执行修改SQL会直接改变本地开发数据。常规课程管理后续通过业务页面完成；控制台用于开发查看、排查和维护。修改课程成员后重新加载页面；修改账号状态或密码后退出并重新登录。密码字段保存BCrypt哈希，不直接填入明文密码。

## 常见问题

- 连接后没有业务表：检查是否误用页面默认的 `jdbc:h2:~/test`，并重新填写上述地址。
- 提示Database not found：确认后端已成功启动且使用demo模式，检查启动目录及实际数据库地址。
- PostgreSQL模式打不开：该模式已关闭H2控制台。切换正式数据库后需要相应的PostgreSQL管理工具。

## 开放范围

控制台仅在demo且未启用postgres配置时开放，只接受回环地址请求。API原有身份认证、权限和CSRF校验保留；仅H2自身控制台使用独立安全配置和同源框架显示规则。该入口不经过前端代理，也不提供课程用户菜单入口。

查询开发数据无需停止后端。直接备份H2数据库文件时，先正常停止后端再复制 `.runtime/demo-db.mv.db`。
