# 接收项目后怎么运行

本交接包包含源码、现有H2演示数据库和已上传材料，已排除node_modules、依赖缓存、构建目录、日志和本地密码配置。解压后使用自己的路径，不要求与发送者相同。

## 一、准备环境

安装Java 21、Maven 3.9+和Node.js（新环境建议22）。在PowerShell中执行以下命令，均能显示版本后再启动：

```powershell
java -version
mvn -version
node -v
npm -v
```

解压到普通文件夹后，用VS Code打开压缩包内的school_system文件夹。在项目根目录打开两个终端：

后端终端：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\backend.ps1
```

前端终端：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\frontend.ps1
```

第一次启动会下载各自电脑上的依赖，需要网络。保持两个终端运行，然后打开 http://127.0.0.1:5173 。

教师teacher01、学生student01、助教assistant01，演示初始密码均为Demo@2026!。若原数据库中的密码被修改，使用实际密码。

127.0.0.1指访问者自己的电脑。组员要在自己电脑上运行后才能用同一地址；无需租服务器，也不用安装PostgreSQL。仅想看发送者电脑的运行画面时可共享屏幕；跨电脑直接访问需要另外配置局域网地址和监听范围。

## 二、停止与再次交接

在前端和后端终端中分别按Ctrl+C，等待退出；PowerShell提示是否终止批处理时输入Y确认。仅关闭浏览器标签页不会停止服务。

服务都停止后再打包。保留backend/.runtime/demo-db.mv.db以及backend/.runtime/files，才能保留数据库和附件。数据库与附件一起复制。新接收者应解压到新目录，确认能启动后再决定如何替换旧版本。

下一次打包排除.cache、node_modules、target、dist、.git、*.log和实际.env文件；保留.env.example。不要删除其他Java或Node程序来解除占用。

## 三、数据库页面

demo模式启动后可打开 http://127.0.0.1:8080/h2-console/ ，连接参数与操作步骤见docs/数据库管理说明.md。
