# 系统一验收测试脚本

使用本地 H2 内存数据库和合成课程材料，覆盖用例 01–18。测试不连接线上系统，也不需要老师的核验账号。

## 运行

需要 Java 21、Maven 3.9+ 和 PowerShell。从仓库根目录打开 PowerShell。

运行全部 18 项：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '.\测试脚本\run-all.ps1'
```

单独运行第 05 项：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '.\测试脚本\case-05.ps1'
```

每个编号脚本只运行对应的测试方法。运行结果由 Maven 输出，详细记录在 `school_system/backend/target/surefire-reports/`。

## 执行结果

2026 年 11 月 26 日在本地执行全部 18 项，18 项通过，失败、错误和跳过均为 0。另行执行 `case-05.ps1` 时仅运行用例 05，结果通过。
